# Kịch bản demo Nông Trí (~5 phút)

1. Giới thiệu Bảng C, vấn đề, persona chú Tư (~1 phút 30).
2. Demo Figma Present, link: https://www.figma.com/proto/foyccQwf5hoeBPOOWD8cWB/BT08-NongTri
   - Trang chủ (cảnh báo rầy nâu) → "Chụp lá, biết bệnh".
   - Màn chụp → nút chụp tròn → Kết quả (độ tin cậy, cảnh báo AI).
   - "Lưu vào nhật ký" → Nhật ký → biểu tượng bánh răng → Quyền riêng tư.
   - Tab Hỏi đáp (nói câu hỏi); tab Giá cả (biểu đồ dự báo, lời khuyên tham khảo).
3. Nhấn mạnh: chỉ số mục tiêu, bảo mật, đạo đức AI, kê khai công cụ AI (trọng tâm chấm Bảng C). Nhắc: dữ liệu mô phỏng.
